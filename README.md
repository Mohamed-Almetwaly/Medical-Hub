# Medical-Hub 🏥

منصة طبية متكاملة تتيح للمستخدمين حجز الكشف، طلب أدوية من الصيدلية، حجز تحاليل معملية، والوصول لخدمات الطوارئ، كل ذلك من مكان واحد.

## ✨ المميزات

- **حجز الدكاترة والعيادات** — تصفح الأطباء، تفاصيلهم، وحجز موعد كشف
- **الصيدلية الإلكترونية** — تصفح وشراء منتجات صيدلية مع سلة تسوق ونظام دفع
- **المعامل والتحاليل** — حجز عينات منزلية أو زيارة معمل، مع اختيار المدينة الأقرب
- **خدمة الطوارئ** — الوصول السريع لخدمات الطوارئ الطبية
- **الرعاية المنزلية** — طلب خدمات رعاية صحية في المنزل
- **حساب المستخدم** — تسجيل دخول، ملف شخصي، وتتبع النشاطات والحجوزات السابقة
- **نظام تنبيهات** — إشعارات وتحديثات للمستخدم

## 🛠️ التقنيات المستخدمة

- HTML5 / CSS3
- JavaScript
- Firebase (قاعدة بيانات وخدمات backend)

## 🚀 طريقة التشغيل

1. حمّل المشروع أو اعمل clone له
2. افتح فولدر المشروع
3. افتح `index.html` مباشرة في المتصفح، أو استخدم إضافة **Live Server** في VS Code لتشغيله محليًا

## ⚙️ الإعداد (Firebase)

المشروع يستخدم Firebase كـ backend. تأكد من ضبط بيانات مشروعك في `firebase-config.js` وتفعيل الـ Security Rules المناسبة في Firebase Console قبل النشر الفعلي.
